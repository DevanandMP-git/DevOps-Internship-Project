# DevOps Training Project

A hands-on DevOps project covering Linux, Git, web hosting, Bash scripting, and Continuous Integration using GitHub Actions.

## CI Pipeline Status

![CI Status](https://github.com/DevanandMP-git/DevOps-Final/actions/workflows/ci.yml/badge.svg)

## Project Modules

### Module 1 – Linux & Git

* Practiced Linux commands and file management.
* Learned file permissions and user management.
* Practiced Git repositories, commits, branches, and merging.

### Module 2 – Web Hosting & Bash Scripting

* Created a basic HTML website.
* Practiced Apache web hosting.
* Created a Bash script for system information.

### Module 3 – CI/CD Workflow

* Configured a GitHub Actions workflow.
* Automated the execution of a Bash script when changes are pushed to the main branch.
* Added a CI status badge.
